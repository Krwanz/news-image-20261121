## How it works

`poster.png` is the finished 1024×576 poster (under 1 MiB). `main.ts` copies
it to `$MAKEFUN_OUTPUT_DIR/entry.png`. Run it locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
